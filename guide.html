POST and PUT body

Use this JSON body for POST /api/records. For PUT /api/records/:id, send the same four fields; the record ID goes in the URL, not the body. Set Content-Type: application/json. The service generates the positive integer ID, ignores any ID you send, and trims input before validation.

  • Title: 3–80 characters
  • Category: 2–40 characters (for example, Network, Software, or Hardware)
  • Description: 5–300 characters
  • Status: Pending, In progress, or Completed
{
  "title": "Campus Wi-Fi unavailable",
  "category": "Network",
  "description": "The campus Wi-Fi disconnects during class.",
  "status": "Pending"
}

Error responses

Errors return a JSON object with a message field. Expect 400 for invalid input or malformed JSON, 404 for unknown routes or records, 413 for oversized bodies, 415 for unsupported encoding, 500 for unexpected errors, and 503 if the health check cannot reach the database.
